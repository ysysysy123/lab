# 灵活教学法与分轮课程设计指南

借鉴 Matt Pocock `teach` 的认知负荷理论，并针对 **数学 → 深度学习 → LLM → Agent → 具身 VLA** 学科特点定制。

---

## 1. 两个阶段的认知原则：获取 vs 巩固

| 维度 | 获取新知（Fluency Acquisition） | 长期留存（Storage Strength） |
|---|---|---|
| **工作记忆策略** | **阻力越小越好**：把符号、图形、数字算例、代码摊开讲清，别藏着掖着让人猜 | **适度合意困难（Desirable Difficulty）**：用回忆检索、间隔复习、跨课串联加深印记 |
| **lab-teach 默认做法** | 正文直接给清直觉、2×2 数字手算、分步推导和完整真实源码讲解 | 页面底部放默认折叠的 `details.reveal.q` 思考卡；按 1/3/7/21 天间隔触发轻量复习；沉淀 `reference/*.html` 速查卡 |
| **何时上强度** | **绝不在初学正文里强行留白卡人** | 用户主动说「练一下 / 盲写 / 考考我」，或进入 `projects/` 写简历核心模块时 |

## 2. 知识依赖分析与 ZPD（最近发展区）定标

收到「开始学习 XX」时，先做 30 秒依赖审计：
1. 查 `学习/learning-records/`、`学习/GLOSSARY.md` 和 `ROADMAP_16W.md` 的 `[x]` 项，确认用户的**已知地板（Floor）**。
2. 对照上层 Notebook 大纲（`study.py learn nb ... --outline`）拆出前置概念，分三类处理：
   - **`✓ 已掌握`**：在页面顶部 `.prereq` 一笔带过并复用既有记号，**绝不从头重教**。
   - **`△ 微小缺口`（3 句话内能补齐）**：不单独拆课，直接在本课 §1 或右侧 `.sidenote` 用一个 2×2 例子顺手补齐。
   - **`🔴 硬前置缺失`（需独立 15 分钟以上理解）**：排进 `计划.md` 的第 1 课先讲它，并在 Mermaid 依赖图中标清先后箭头。
3. **分课粒度**：每个课题拆为 **3–6 节小课**，每节课对应 1 个具体、可观察的「掌握标志」（如「能看着计算图手算出多路复用的梯度累加结果」，而不是空泛的「理解反向传播」）。

## 3. 五类知识点的教学结构裁剪（拒绝千篇一律！）

不要每节课都硬凑相同的八个小节，按知识本质选最匹配的组合：

1. **数学与损失函数类**（交叉熵、KL 散度、RoPE 旋转不变性、DPO 消去 RM、GRPO 组内优势、雅可比阻尼最小二乘）
   - 黄金动线：**上代痛点（为什么旧公式炸/贵） → 2×2 极小具体数字手算 → `.lab-stepper` 分步符号推导（每步注明用了哪条恒等式） → 滑块调节关键超参（温度 $\tau$ / $\beta$ / 阻尼 $\lambda$）看曲线变化**。
2. **神经网络与大模型架构类**（MLP、Causal Self-Attention、MQA/GQA、RMSNorm+SwiGLU、ViT/LLaVA Projector、ACT/Diffusion Policy）
   - 黄金动线：**架构动机 → `table.shape` 全链路张量维度追踪表 → 玩具维度（$B{=}1, T{=}3, d{=}2$）前向走一遍 → 真实源码 `.code-walk` 逐行对齐 → 热力图/结构图可视化**。
3. **训练动态与 AI Infra 类**（初始化方差、混合精度 BF16/FP16、显存账本口算、KV Cache 与 PagedAttention、AWQ 量化）
   - 黄金动线：**真实故障现象（NaN / OOM / 吞吐卡死） → 字节级账本算式 → 交互式显存/吞吐计算器（默认填入本机 4080 12GB 与远程 A800 80GB 预设！） → 训练配置代码防坑清单**。
4. **Agent 与工程协议类**（BPE 分词、ReAct 循环、上下文压缩、BM25+Dense RRF 混合检索、MCP Server、Pass@k 评估）
   - 黄金动线：**边界失效案例（纯 Prompt 幻觉 / 单路向量漏检关键词） → 状态机或轨迹逐步回放（`.lab-stepper` + `LabPlot.graph`） → `projects/p2-scratch-agent` 真实代码拆解**。
5. **机器人运动学与具身控制类**（$SO(3)/SE(3)$ 变换、DH 正逆运动学、轨迹多峰分布危机、VLA 动作离散化 vs 流匹配）
   - 黄金动线：**2D 平面二连杆几何直觉（画在 `LabPlot.chart` 上直接拖拽目标点！） → 矩阵/雅可比公式 → 奇异位形边界行为观察 → 映射到 `p4-robot-learning` 代码**。

## 4. 章节复习与知识压缩（防遗忘闭环）

- `course.py` 基于 `1 → 3 → 7 → 21 天` 间隔自动计算每个课题的建议复习日，并在 `study.py status` 和 `学习/index.html` 显示 `⏰ 建议复习`。
- 当用户说「复习」或「整理笔记」时：
  1. **不重贴长篇讲义**：提炼 3–5 个核心连接问题（先让用户脑中过一遍，再点开折叠答案核对）。
  2. **构建或更新 `学习/reference/<slug>.html` 速查表**：课程页是学习时的脚手架，速查表才是日后写项目和面试前反复翻看的高密度资产（一页看全核心公式 + Shape + 15 行代码核 + 30 秒面试表达）。
  3. **更新 `GLOSSARY.md`**：只有当某个概念已经学完并用顺后，才浓缩成 1–2 句话写入术语表。
