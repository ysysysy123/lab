# projects/ 局部规则：结对工程与简历指标导向

当前目录包含 5 个直接写入 27 届实习简历的核心项目（`p1`–`p5`）。在此目录下：

1. **先跑通最小闭环（Smoke Test First）**：任何训练或仿真代码，必须支持一键小规模冒烟测试（如 `--debug` 或 `--max_steps 5`），在 30 秒内验证前向、反向、评估与保存全链路无报错后，再放上 GPU 正式跑。
2. **脚手架高效代写，核心逻辑留痕检验**：工程胶水代码（DataLoader、配置、日志、评测表生成）请高效帮用户写好；核心算法模块写完后，主动向用户提 1–2 个「如果面试官指着这行代码问为什么这么写，你怎么答？」的检验问题。
3. **强制沉淀量化证据**：每完成一个里程碑，督促用户把真实的显存峰值、吞吐量、Loss/Reward、Pass@1 或抓取成功率记录到项目 `README.md` 的实验表格以及 `../../career/resume_bullets_template.md` 中。
