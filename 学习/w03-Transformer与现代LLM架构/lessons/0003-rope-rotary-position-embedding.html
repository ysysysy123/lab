本课收获

用二维旋转矩阵与复数欧拉公式双路径证出核心恒等式 $(R_m q)^\top (R_n k) = q^\top R_{n-m} k$，手算验证整句平移前后内积小数点后 12 位完全相等，并讲清「高低频时针分工 · 完美兼容 KV Cache · 调大 rope_theta 长文本外推」三大面试高频追问。

前置依赖： ✓ 缩放点积自注意力 SDPA 与多头重排（本课题第 1–2 课） · △ 二维平面旋转公式与欧拉公式 $e^{i\phi} = \cos\phi + i\sin\phi$（本课 §3 一步步展开，零跳步）

01痛点与直觉：给「顺序盲」注意力装上一对双人华尔兹表针

前两课手撕出的自注意力有一个令人惊讶的盲区：如果不加因果掩码与位置信息，纯 Self-Attention 对词序完全是个「瞎子」（排列等变性，Permutation Equivariance）！

把「狗 咬 人」换成「人 咬 狗」，只是把输入矩阵 $X$ 的第 0 行和第 2 行对调。对于「咬」这个词的 Query 来说，点积集合 $\{q_{\text{咬}}\cdot k_{\text{狗}},\ q_{\text{咬}}\cdot k_{\text{人}}\}$ 分毫不差，加权求和算出的「咬」字向量连小数点最后一位都完全相同——模型根本分不清到底是谁咬了谁！

绝对相加的混杂痛点：初代 Transformer 在最底层把词向量直接加上绝对位置向量 $\tilde{x}_m = x_m + p_m$。算 $QK^\top$ 时会展开成 $x_m^\top W_Q^\top W_K x_n + x_m^\top W_Q^\top W_K p_n + p_m^\top W_Q^\top W_K x_n + p_m^\top W_Q^\top W_K p_n$ 四项大杂烩，而且一旦测试长度超过训练长度，没见过的新位置向量立刻让注意力崩盘。

苏剑林（Su et al., RoFormer）提出的 旋转位置编码（Rotary Position Embedding, RoPE） 如今已成为 LLaMA、Qwen、DeepSeek、MiniMind 的绝对标配。它的破局思路极其优雅：

时钟双针直觉：不加偏置、不碰 Value，只把 Q 和 K 按位置原地转圈！

想象把二维向量 $q$ 和 $k$ 看作表盘上的两根指针：
• 如果某个词排在第 $m$ 个位置，我们就把它的指针逆时针原地旋转 $m\theta$ 弧度（位置 1 转 $1\theta$，位置 3 转 $3\theta$）；
• 两个向量的点积 $\langle u, v \rangle = \|u\|\,\|v\|\cos\alpha$ 只取决于它们的模长和两针之间的夹角 $\alpha$！
• 当整段话往后平移 $s$ 个词（从位置 $(1, 3)$ 变成 $(5, 7)$），两根指针同步多转了 $s\theta$ 角——就像跳双人华尔兹的舞伴一起转圈，它们各自的模长没变，彼此之间的夹角差 $(n - m)\theta$ 也没变，因此注意力点积分数恒定不变！

022D 极小数字手算：亲眼见证「向量全变，内积纹丝不动」

别只信直觉，我们拿一组极简二维数字亲手算一遍（已由 verify_0003.py 双精度核验）：取原始查询向量 $q = [1.0,\ 0.5]^\top$，键向量 $k = [0.8,\ 1.2]^\top$，单位步旋转角 $\theta = 0.5\text{ rad}$（约 $28.65^\circ$）。二维逆时针旋转公式为：

$$R_\phi \begin{pmatrix} x_0 \\ x_1 \end{pmatrix} = \begin{pmatrix} x_0 \cos\phi - x_1 \sin\phi \\ x_0 \sin\phi + x_1 \cos\phi \end{pmatrix}$$

现在让这对词均保持相对距离 $\Delta = n - m = 2$，分别放在句子开头的位置组 A $(m=1, n=3)$ 与往后平移 4 格后的位置组 B $(m=5, n=7)$：

看到奇迹了吗？从位置 $(1, 3)$ 平移到 $(5, 7)$，四个坐标连正负号和象限都面目全非，但把它们做内积相乘相加后，前 12 位小数一字不差地收敛回 0.083246440369——它严格等于直接把 $k$ 旋转相对角 $(3-1)\theta = 1.0\text{ rad}$ 后与 $q$ 的内积 $q^\top R_2 k$！

03面试必推公式：从 2D 旋转恒等式到 $d$ 维多频时钟

面试官让你「手推一下 RoPE 为什么能用绝对位置实现相对位置编码」时，按下面 4 步写到白板上就是满分：

对位置索引 $m \in \{0, 1, 2, \dots\}$ 与基频 $\theta$，定义 $2\times 2$ 旋转矩阵：

$$R_m = \begin{pmatrix} \cos m\theta & -\sin m\theta \\ \sin m\theta & \cos m\theta \end{pmatrix}$$

验证正交性：$R_m^\top R_m = \begin{pmatrix} \cos^2 m\theta + \sin^2 m\theta & 0 \\ 0 & \sin^2 m\theta + \cos^2 m\theta \end{pmatrix} = I_2$。因此 $\|R_m q\|_2 = \|q\|_2$——旋转完全不改变向量的模长与二阶矩，第 1 课辛苦证明的 $1/\sqrt{d_k}$ 方差稳定性被 100% 完好保留！

利用偶函数 $\cos(-m\theta) = \cos m\theta$ 与奇函数 $\sin(-m\theta) = -\sin m\theta$，矩阵转置恰等于反向旋转 $-m\theta$：

$$R_m^\top = \begin{pmatrix} \cos m\theta & \sin m\theta \\ -\sin m\theta & \cos m\theta \end{pmatrix} = R_{-m}$$

再由两角差公式 $\cos\alpha\cos\beta + \sin\alpha\sin\beta = \cos(\beta-\alpha)$ 与 $\cos\alpha\sin\beta - \sin\alpha\cos\beta = \sin(\beta-\alpha)$，两矩阵连乘等价于角度相减：

$$R_m^\top R_n = \begin{pmatrix} \cos m\theta \cos n\theta + \sin m\theta \sin n\theta & -\cos m\theta \sin n\theta + \sin m\theta \cos n\theta \\ -\sin m\theta \cos n\theta + \cos m\theta \sin n\theta & \sin m\theta \sin n\theta + \cos m\theta \cos n\theta \end{pmatrix} = \begin{pmatrix} \cos(n-m)\theta & -\sin(n-m)\theta \\ \sin(n-m)\theta & \cos(n-m)\theta \end{pmatrix} = R_{n-m}$$

计算位置 $m$ 的旋转后查询 $R_m q$ 与位置 $n$ 的旋转后键 $R_n k$ 的点积：

$$\langle R_m q,\ R_n k \rangle = (R_m q)^\top (R_n k) = q^\top \bigl(R_m^\top R_n\bigr) k = q^\top R_{n-m} k$$

复数视角一行证法：把二维向量看成复数 $\tilde{q} = q_0 + i q_1$，旋转 $m\theta$ 就是乘单位复数 $e^{im\theta}$；实向量内积等于复数乘共轭取实部：

$$\operatorname{Re}\!\Bigl[(\tilde{q} e^{im\theta})\cdot(\tilde{k} e^{in\theta})^*\Bigr] = \operatorname{Re}\!\Bigl[\tilde{q}\tilde{k}^* e^{i(m-n)\theta}\Bigr]$$

结果只含相对距离 $(m - n)$，彻底消去了绝对坐标 $m, n$！更妙的是：编码阶段对 $q_m$ 只乘 $R_m$、对 $k_n$ 只乘 $R_n$（单侧只依赖自身绝对下标），历史 Token 的 $R_n k_n$ 算完存进 KV Cache 后，未来生成第 $1000$ 个词时缓存里的 Key 一个字都不用重算！

单头维度 $d$（偶数，如 $64$ 或 $128$）怎么办？把 $d$ 个维度两两配成 $d/2$ 对独立二维平面，构造块对角旋转矩阵 $R_{\Theta, m}^d = \operatorname{diag}(R_{m\theta_0}, R_{m\theta_1}, \dots, R_{m\theta_{d/2-1}})$，各对子平面采用几何递减角频率：

$$\theta_j = \text{base}^{-2j / d}, \qquad j \in \{0, 1, \dots, d/2 - 1\}$$

以 $d = 8,\ \text{base} = 10000$ 为例，$\theta = [1.0,\ 0.1,\ 0.01,\ 0.001]$，对应转满一圈的波长 $\lambda_j = 2\pi / \theta_j$ 从 $6.28$ 个词跨越到 $6283$ 个词：
• 前几组高频对（秒针，$\theta_0 = 1$）：每走 1 格就大角度转动，专职分辨「狗咬人 vs 人咬狗」的精细相邻语序；
• 后几组低频对（时针，$\theta_{d/2-1} \ll 1$）：走几千个词才缓缓偏转，负责跨段落的宏观远程依赖；
• 天然远程衰减：不同频率余弦波 $\sum_j \cos\bigl((m-n)\theta_j\bigr)$ 在 $|m-n|=0$ 时同相叠加达到峰值，距离拉远后高频波迅速正负相消，形成平滑的「近处关注强、远处渐衰减」先验包络！

(d 维 RoPE 工程展开式)

$$R_{\Theta, m}^d x = x \odot \cos(m\Theta) + \operatorname{rotate\_half}(x) \odot \sin(m\Theta)$$

$x \in \mathbb{R}^{d}$
单头 Query 或 Key 向量（切两半记为 $[x_{\text{前}},\ x_{\text{后}}]$，每半长度 $d/2$）
$\operatorname{rotate\_half}(x)$
$[-x_{\text{后}},\ x_{\text{前}}]$，把矩阵乘里的 $-x_1\sin\theta$ 与 $+x_0\sin\theta$ 变成一次零矩阵构造的切片取反拼接
$\text{base}$
频率底数：LLaMA-1/2 为 $10^4$；LLaMA-3 ($5\times 10^5$)、Qwen2.5 / MiniMind ($10^6$) 调大底数以支撑 32K–128K 长上下文

04代码讲解：绝不构造稀疏矩阵的 $O(d)$ 极速旋转

如果真的在代码里建一个 $d \times d$ 的块对角矩阵做矩阵乘，要白白算 $d^2 - 2d$ 个零元素！工业界一律用 复数逐元素乘 或等价的 rotate_half 实数逐元素乘，复杂度仅 $O(d)$。左侧截取自 09-MiniMind整体架构.ipynb · Cell#11：

def precompute_freqs_cis(dim, max_len, theta):
    """频率表：freq_cis[i] = e^{i·θ_i}（复数形式，θ_i 按维度递减）。"""
    freqs = 1.0 / (theta ** (np.arange(0, dim, 2) / dim))   # [dim/2]
    t = np.arange(max_len)
    angles = np.outer(t, freqs)                              # [max_len, dim/2]
    return np.exp(1j * angles)                               # [max_len, dim/2]

def apply_rotary(x, freqs_cis):
    """旋转 x：[..., dim] 每对 (x0,x1) -> (x0·cosθ − x1·sinθ, x0·sinθ + x1·cosθ)。
    复数法：拆成 halves 组合复向量乘以 e^{iθ} 再拼回（与源码 rotate_half 等价）。"""
    d = x.shape[-1]; half = d // 2
    xr = x[..., :half] + 1j * x[..., half:]                  # 复向量 [..., half]
    rot = xr * freqs_cis                                     # 乘以旋转因子
    return np.concatenate([rot.real, rot.imag], axis=-1)

freqs_cis = precompute_freqs_cis(cfg['head_dim'], cfg['max_position_embeddings'], cfg['rope_theta'])
print('freqs_cis 形状', freqs_cis.shape, '| 频率（弧度）：', np.round(np.angle(freqs_cis[0, :4]), 3))
q_sample = np.random.randn(B, 1, cfg['num_attention_heads'], cfg['head_dim'])
q_rot = apply_rotary(q_sample, freqs_cis[0])
print('Q 第 1 位置旋转:', q_sample.shape, '->', q_rot.shape)
  1. 一次性预计算旋转表：np.arange(0, dim, 2) / dim 生成 $2j/d$；外积 outer(t, freqs) 一次性造出 (max_len, dim/2) 角度表并转为单位复数 $e^{im\theta_j}$，模型初始化时缓存为 Buffer，训练零重复开销。
  2. 前半实部 · 后半虚部配对：把第 $j$ 维与第 $j + d/2$ 维配成一对 2D 子平面（HuggingFace LLaMA/Qwen 标准布局；原版 Meta LLaMA 则是相邻偶数奇数维配对，两者正交等价，但加载开源权重时切勿混用！）。
  3. 复数乘法还原实数：$(x_0 + i x_1)(\cos\phi + i\sin\phi) = (x_0\cos\phi - x_1\sin\phi) + i(x_0\sin\phi + x_1\cos\phi)$，取实部虚部拼回即得旋转结果。
  4. Decode 单步切片：推理生成新词时 q_sample 序列维长度为 1，只需取当前位置那一行 freqs_cis[pos] 旋转即可！

def apply_rotary_emb_numpy(x, freqs_cis):
    """把 x(T,d) 每对相邻维度 (x1,x2) 看作复数 x1+i·x2，乘对应位置 e^{iθ} 完成旋转，再拆回实数"""
    T = x.shape[0]
    x_ = x.reshape(T, -1, 2)                              # (T, d/2, 2)：最后一维 [x1,x2]
    x_c = (x_[:, :, 0] + 1j * x_[:, :, 1]).astype(np.complex64)  # 转复数 (T,d/2)
    x_r = x_c * freqs_cis                                 # 复数乘法 = 旋转
    out = np.stack([x_r.real, x_r.imag], axis=-1)         # 实部第1列、虚部第2列
    return out.reshape(T, -1)                             # 还原 (T,d)

06小结与面试表达模板

本课核心四条
  • 绝对形式 · 相对内核：对位置 $m$ 的 $q$ 独立左乘正交旋转矩阵 $R_m$，对位置 $n$ 的 $k$ 左乘 $R_n$，点积 $(R_m q)^\top (R_n k) = q^\top R_{n-m} k$ 自动只依赖相对距离 $n - m$。
  • 正交保模长：$\|R_m q\|_2 = \|q\|_2$，零可学习参数、不改变向量范数与点积方差，与 $\sqrt{d_k}$ 缩放天然契合。
  • 高低频多尺度分工：$d/2$ 对二维子平面按 $\theta_j = \text{base}^{-2j/d}$ 几何递减，高频管相邻词序，低频管长程依赖，多频叠加自带远程衰减包络。
  • 工程双杀优势：用 `rotate_half` 逐元素乘实现 $O(d)$ 开销，且因单侧只依赖自身位置下标，历史旋转后的 Key 可直接固化进 KV Cache 终身复用。
30 秒面试高分回答模板

「RoPE 的核心思想是用绝对位置的旋转操作实现相对位置注意力。它把单头 $d$ 维向量两两分组看作 $d/2$ 个二维复平面向量，在位置 $m$ 处给 Query 和 Key 分别乘上正交旋转矩阵 $R_{m\theta_j}$。由于 $R_m^\top R_n = R_{n-m}$，算注意力点积时 $(R_m q)^\top (R_n k) = q^\top R_{n-m} k$，绝对位置自动抵消，只剩相对距离 $n-m$。相比加性绝对位置编码外推差、传统相对位置偏置破坏 KV Cache 或 FlashAttention 对齐，RoPE 既保持模长不变、零额外参数，又能让历史旋转后的 Key 直接缓存进 KV Cache，并通过多频几何级数兼顾局部语序与远程衰减。」

07想检验一下？（可选 · 点击展开）

1. 🎤 面试追问（第一层：机制边界）：为什么 RoPE 只旋转 Query 和 Key，绝对不去旋转 Value？

分工完全不同：
• $Q, K$ 负责「寻址打分」：我们需要根据两个词相隔多远 $(m - n)$ 来调整匹配权重，旋转 $Q_m, K_n$ 算内积时绝对相位抵消，恰好留下纯粹的相对距离 $R_{n-m}$。
• $V$ 负责「传递语义内容」：如果把 $V_n$ 也旋转成 $R_n v_n$，输出加权求和 $o_m = \sum_n a_{mn} R_n v_n$ 外面并没有 $R_m^\top$ 来抵消相位！这意味着同一个短语从句子开头平移到句子中间，算出的注意力权重 $a_{mn}$ 虽然一样，聚合出的输出向量 $o_m$ 却被强行拧转了一个绝对角度 $s\theta$，后续 FFN 层就无法平移不变地复用特征了（除非输出前再额外左乘一次 $R_m^\top$ 抵消，徒增计算量）。

2. 🎤 面试追问（第二层：系统工程与 KV Cache）：为什么早期相对位置编码（如 Shaw et al. 2018 注入 Key 向量）不兼容 KV Cache，而 RoPE 完美兼容？跟 ALiBi / T5 相比又赢在哪？

1. 对比早期相对向量注入（$k_{m,n} = W_K x_n + p_{m-n}$）：Key 向量本身依赖当前查询位置 $m$！每当自回归新生成第 $m+1$ 个词，前面所有历史词相对它的距离都从 $m-n$ 变成了 $m+1-n$，缓存里的 Key 全部作废，每步都得花 $O(T^2)$ 重算，KV Cache 彻底失效。而 RoPE 把相对耦合拆解成了可分离双边变换 $f(q, m)=R_m q,\ g(k, n)=R_n k$，第 $n$ 个词的 Key 旋转角永远是固定的 $n\theta$，算一次存进缓存终身不改！
2. 对比分数偏置路线（ALiBi / T5 Bias）：ALiBi 和 T5 需要在 $T \times T$ 分数矩阵上加偏置矩阵 $B_{ij}$。在接入 FlashAttention 内核时，任意可学习的 T5 分桶偏置需要从显存额外加载 bias 块拖慢核函数；而 ALiBi 的硬线性惩罚 $-m|i-j|$ 缺乏 RoPE 通过 $Q, K$ 内容自适应学习复杂远程跳跃（如代码跨百行括号闭合、长文首尾呼应）的表达自由度。

3. 🎤 面试追问（第三层：前沿长上下文外推）：把 4K 预训练模型扩展到 128K 长上下文时，为什么要把 rope_theta（base）从 $10^4$ 调大到 $5\times 10^5$ 或 $10^6$（NTK-aware Scaling / ABF）？

根源在于低频维度的分布外（OOD）越界：
• 在 4K 训练长度下，高频维度早就转了几百圈（$0 \sim 2\pi$ 全角度都被模型充分见过了）；但最低频维度（$\theta \approx 10^{-4}$）在 $m = 4096$ 时最多只转到 $0.41\text{ rad}$（连四分之一圈都没见过！）。一旦推理强行喂入 $m = 100,000$，低频时针突然转到从未见过的负半平面，注意力分数立刻崩溃乱码。
• 如果简单用线性位置插值（PI）把所有位置除以放大倍数 $s=32$（$m \leftarrow m/32$），虽然低频不越界了，但高频秒针也被慢放了 32 倍，相邻几个词全挤在微小角度里分不清前后，短距离困惑度（PPL）明显恶化。
• 调大底数 `base`（NTK-aware Scaling）利用指数 $\theta_j = \text{base}^{-2j/d}$ 的非均匀特性：当 $j=0$ 时 $\text{base}^0 = 1$（最高频指针完全不缩放，100% 保住局部字词分辨率！）；当 $j \to d/2$ 时指数接近 $-1$（最低频时针按比例大幅减速，确保 128K 长度下依然留在模型熟悉的象限内！）这就是「高频不插值、低频做插值」的精髓。
