01痛点与直觉：网络叠到 32 层为什么训不动？

如果把 32 层神经网络简单首尾串接成 $x_{l+1} = F_l(x_l)$，没有任何残差旁路或归一化，会发生什么？无论是前向激活尺度还是反向传播的雅可比矩阵，都会变成 32 次连乘：

  • 若每层有效缩放因子略大于 $1$（比如 $1.5$），穿过 32 层后变为 $1.5^{32} \approx \mathbf{4.31 \times 10^5}$——前向数值与反向梯度瞬间指数级爆炸，FP16 直接打出 NaN；
  • 若每层缩放因子略小于 $1$（比如 $0.7$），穿过 32 层后只剩 $0.7^{32} \approx \mathbf{1.10 \times 10^{-5}}$——顶层误差传到底层已经衰减近 9 万倍，前几层权重彻底「冻死」（梯度消失）。
大模型到底有多深？ Llama-2-7B 有 32 个 Block（共 64 个子层：32 个 Attention + 32 个 FFN）；Llama-3-70B 高达 80 个 Block（160 个子层）；DeepSeek-V3 有 61 层。没有残差与归一化，超过 8 层就几乎无法收敛。

现代开源 LLM 能稳稳堆到上百层，全靠两根定海神针协同工作：Pre-Norm 残差连接（保反向梯度畅通无阻） + RMSNorm（保每层子层输入幅度恒定且极省带宽）。

立交主干高速 vs 匝道限速站

Post-Norm（2017 原版 Transformer）相当于把归一化收费站建在主干高速路上：每过一层，主干信号和回传梯度都要被强行除以一次标准差 $\sigma$，层数一深照样衰减；
Pre-Norm（LLaMA / Qwen / MiniMind 现代标配）把归一化挪到了进入子层的支路匝道口：主干从第 1 层到最后一层是 100% 纯净加法直通车，顶层梯度零损耗直达底层！

02残差高速公路与 Pre-Norm vs Post-Norm 生死差异

点击下方「下一步」（或按键盘 ← →），一步步推导残差连接如何改写反向传播链式法则，并对比图上回传路径的本质区别：

设第 $l$ 层输入为 $x_l \in \mathbb{R}^d$，子层变换（Attention 或 FFN）记为 $F_l(\cdot)$。残差连接不再让子层直接拟合目标映射，而是只学习叠加在原输入上的增量：

$$x_{l+1} = x_l + F_l(x_l)$$

将上式从任意浅层 $l$ 一路递归展开到顶层 $L$，主干输入被完好保留，所有深层输出只是沿途增量的累加：

$$x_L = x_l + \sum_{i=l}^{L-1} F_i(x_i)$$

这一步用多元链式法则对浅层激活 $x_l$ 求损失 $\mathcal{L}$ 的梯度（回忆 w01 第 1 课：加法门 $a+b$ 对两侧输入的局部导数恒为 $1$，推广到向量就是单位矩阵 $\mathbf{I}$！）：

$$\frac{\partial \mathcal{L}}{\partial x_l} = \frac{\partial \mathcal{L}}{\partial x_L}\frac{\partial x_L}{\partial x_l} = \frac{\partial \mathcal{L}}{\partial x_L}\!\left(\mathbf{I} + \frac{\partial}{\partial x_l}\sum_{i=l}^{L-1} F_i(x_i)\right)$$

盯紧括号里那个与权重完全无关的单位阵 $\mathbf{I}$：原本危险的「连乘积 $\prod J_i$」被改写成了「$\mathbf{I} + \text{支路项}$」！哪怕训练初期残差支路权重全接近 $0$，顶层梯度 $\frac{\partial \mathcal{L}}{\partial x_L}$ 也能沿着 $\mathbf{I}$ 原封不动直达第 1 层。

把归一化层 $\text{Norm}(\cdot)$ 塞进残差块时，位置差半步，反向动力学天差地别：

  • Post-Norm（2017 原版）：$x_{l+1} = \text{LN}\big(x_l + F_l(x_l)\big)$。归一化卡死在残差主干上！初始化时若 $\text{Var}(x_l)=1,\ \text{Var}(F_l)=\alpha^2$，相加后方差膨胀为 $1+\alpha^2$，每次反向穿过 $\text{LN}$ 主干梯度都要被乘上缩放因子 $\frac{1}{\sqrt{1+\alpha^2}} < 1$。32 层连乘下来底层梯度大幅缩水，而顶层梯度极大——必须配数千步 Learning Rate Warmup 小心翼翼热身，否则起步直接梯度爆炸崩盘。
  • Pre-Norm（GPT-2/3、LLaMA、Qwen、MiniMind 全员采用）：$x_{l+1} = x_l + F_l\big(\text{RMSNorm}(x_l)\big)$。归一化退居残差支路入口，主干从词嵌入直到最后一层 final RMSNorm 是 100% 纯加法高速公路，各层梯度范数均匀平稳，支持更大峰值学习率稳健收敛！
架构范式单层递推公式主干反向连乘因子训练表现与代表模型
Plain Net（无残差）$x_{l+1} = F_l(x_l)$$\prod_{i=l}^{L-1} J_{F_i}$（指数爆炸或消失）超过 8–12 层极难直接收敛（早期 VGG）
Post-Norm$x_{l+1} = \text{LN}(x_l + F_l(x_l))$主干每层乘 $\approx \frac{1}{\sqrt{1+\alpha^2}}$强依赖长 Warmup，超深层易崩（2017 Transformer / BERT）

03从 BatchNorm → LayerNorm → RMSNorm：4 维向量手算对比

一句话分清 BatchNorm vs LayerNorm：为什么 NLP 绝不用 BN？

BatchNorm（CV 常用）跨样本对同一通道求均值方差（沿 $(B, T)$ 维归约）：但在大模型里，一个 Batch 内句子长短不一、尾部塞满无意义的 <pad> 会严重污染统计量；更致命的是自回归推理时往往 Batch=1, T_cur=1，跨样本统计直接失灵！
LayerNorm / RMSNorm 则在每个 Token 自己的特征维 $d$（最后一维 axis=-1）上独立归一化：输入形状 (B, T, d) 算出统计量形状 (B, T, 1)，与 Batch 大小、序列长度、Padding 掩码 100% 解耦，训练与推理行为完全一致！

总体方差口径提醒（取自 05-层归一化LayerNorm.ipynb Cell#4）：LayerNorm 求方差除以特征维 $d$（无偏估计 $d-1$ 的贝塞尔校正不用），对应 PyTorch var(..., unbiased=False)。

具体数字手算：同一组 4 维特征过 LayerNorm vs RMSNorm

取单个 Token 的 $d=4$ 维向量 $x = [2.0,\ -1.0,\ 3.0,\ 0.0]$，初始缩放 $\gamma = [1, 1, 1, 1]$，偏置 $\beta = [0, 0, 0, 0]$，防除零常数 $\epsilon = 10^{-5}$（所有小数均经 verify_0004.py 与 PyTorch nn.LayerNorm / nn.RMSNorm 双重校验）：

先求均值中心化，再求方差缩放
  1. 第 1 趟归约求均值 $\mu$： $$\mu = \frac{1}{4}(2.0 - 1.0 + 3.0 + 0.0) = \mathbf{1.0}$$
  2. 减去均值中心化：$x - \mu = [1.0,\ -2.0,\ 2.0,\ -1.0]$（此时元素和严格为 $0$）。
  3. 第 2 趟归约求总体方差 $\sigma^2$： $$\sigma^2 = \frac{1}{4}\big(1.0^2 + (-2.0)^2 + 2.0^2 + (-1.0)^2\big) = \frac{10}{4} = \mathbf{2.5}$$
  4. 除以标准差缩放：$\sqrt{\sigma^2 + \epsilon} = \sqrt{2.50001} \approx \mathbf{1.581142}$，逐元素相除得： $$\hat{x}_{\text{LN}} = \frac{x - \mu}{\sqrt{\sigma^2 + \epsilon}} \approx \mathbf{[0.632454,\ -1.264909,\ 1.264909,\ -0.632454]}$$
砍掉均值 $\mu$ 与偏置 $\beta$，只按均方根 RMS 缩放
  1. 唯一 1 趟归约求均方值 $\text{mean}(x^2)$： $$\frac{1}{4}\big(2.0^2 + (-1.0)^2 + 3.0^2 + 0.0^2\big) = \frac{4 + 1 + 9 + 0}{4} = \frac{14}{4} = \mathbf{3.5}$$
  2. 求均方根因子 $\text{RMS}(x)$： $$\text{RMS}(x) = \sqrt{3.5 + 10^{-5}} = \sqrt{3.50001} \approx \mathbf{1.870831}$$
  3. 直接缩放输出（原向量中的 $0.0$ 依然保持 $0.0$，不做平移！）： $$y_{\text{RMS}} = \frac{x}{\text{RMS}(x)} \odot \gamma \approx \mathbf{[1.069043,\ -0.534522,\ 1.603565,\ 0.000000]}$$
RMSNorm

$$\text{RMS}(x) = \sqrt{\frac{1}{d}\sum_{i=1}^{d} x_i^2 + \epsilon}, \qquad y = \frac{x}{\text{RMS}(x)} \odot \gamma$$

$x \in \mathbb{R}^{B \times T \times d}$
子层输入张量，归约仅沿最后一维特征维 $d$ 进行，统计量形状为 $(B, T, 1)$
$\gamma \in \mathbb{R}^d$
唯一可学习逐通道缩放向量（初始化全 $1$；彻底去掉了偏置参数 $\beta$，参数量省一半）
$\epsilon \in \{10^{-6}, 10^{-5}\}$
防零向量除零微扰项（LLaMA / MiniMind 默认取 1e-6），必须加在根号内部
提速 10%–30% 的真相
归一化算子计算量极小，瓶颈全卡在 GPU HBM 显存带宽读写（Memory-Bandwidth Bound）！Zhang & Sennrich (2019) 证明均值中心化对精度几乎无贡献，砍掉 $\mu$ 后省去一趟跨线程归约同步与一次全局读写，算子融合后实测显著提速
选读深挖：LayerNorm vs RMSNorm 反向传播输入梯度公式对比（少掉哪一项？）

对照 05-层归一化LayerNorm.ipynb Cell#6 与 Cell#14 的链式展开：记 $\hat{dx} = d\text{out} \odot \gamma$，归一化输出记为 $\hat{x}$。

LayerNorm 反向梯度有 3 条链式路径（$\hat{x}$ 直传、方差 $\sigma^2$ 依赖 $x$、均值 $\mu$ 依赖 $x$），化简后为：

$$\frac{\partial \mathcal{L}}{\partial x}\Big|_{\text{LN}} = \frac{1}{\sqrt{\sigma^2 + \epsilon}}\Big(\hat{dx} \;-\; \underbrace{\mathrm{mean}(\hat{dx})}_{\text{抵消 }\mu\text{ 移动}} \;-\; \hat{x}\odot\mathrm{mean}(\hat{dx}\odot\hat{x})\Big)$$

RMSNorm 反向梯度因为没有均值中心化，直接砍掉了中间的 $-\mathrm{mean}(\hat{dx})$ 归约项：

$$\frac{\partial \mathcal{L}}{\partial x}\Big|_{\text{RMS}} = \frac{1}{\text{RMS}(x)}\Big(\hat{dx} \;-\; \hat{x}\odot\mathrm{mean}(\hat{dx}\odot\hat{x})\Big)$$

取上游梯度 $d\text{out} = [1.0, -0.5, 0.2, 0.8]$ 在本节 $x = [2, -1, 3, 0]$ 处验证：$dx_{\text{LN}} \approx [0.2941, -0.3510, -0.3131, 0.3700]$（分量和必为 $0$），而 $dx_{\text{RMS}} \approx [0.2978, -0.1489, -0.2482, 0.4276]$（与径向 $x$ 点积必为 $0$，因为缩放不改变方向只投影到球面切空间！）。

04代码讲解：MiniMind RMSNorm 与 MiniMindBlock 源码拆解

先看 09-MiniMind整体架构.ipynb 中的核心模块实现，再重点拆解工业级混合精度（BF16 / FP16）训练时最容易踩爆 NaN 的数据类型转换细节：

模块一：RMSNorm 前向原理与工业级 PyTorch 混合精度防坑

class RMSNorm:
    def __init__(self, dim, eps=cfg['rms_norm_eps']):
        self.gamma = np.ones(dim)                 # 可学习缩放，初始全 1
        self.eps = eps
    def __call__(self, x):
        rms = np.sqrt(np.mean(x ** 2, axis=-1, keepdims=True) + self.eps)
        return x / rms * self.gamma

x_in = np.random.randn(B, T, cfg['hidden_size'])
out = RMSNorm(cfg['hidden_size'])(x_in)
print('RMSNorm  :', x_in.shape, '->', out.shape, '| 每行 RMS≈1：', np.round(np.sqrt(np.mean(out**2, -1))[0, :3], 4))
  1. 参数精简：只注册长度为 dim 的缩放向量 gamma（PyTorch 中为 nn.Parameter(torch.ones(dim))），初始化全 1 保证起步等价于单位尺度变换，无偏置 beta。
  2. 最后一维独立归约：axis=-1, keepdims=True 把 (B, T, d) 压成 (B, T, 1)，每个 Token 只算自己的均方根，随后利用广播机制完成逐通道缩放。
  3. 不改变张量形状：输入输出严格同为 (B, T, hidden_size)，初始阶段每行输出向量的均方根 $\sqrt{\text{mean}(y^2)} \approx 1.0000$。
工业级核心防坑：为什么 PyTorch 版 RMSNorm.forward 必须先 .float() 再 .type_as(x)？

在 LLaMA、Qwen 与 MiniMind 的真实 PyTorch 训练源码中，RMSNorm.forward 绝不会直接在半精度张量上算 x ** 2，而是严格写成下面三步：

class RMSNorm(nn.Module):
    def __init__(self, dim: int, eps: float = 1e-6):
        super().__init__()
        self.eps = eps
        self.weight = nn.Parameter(torch.ones(dim))

    def _norm(self, x: torch.Tensor) -> torch.Tensor:
        return x * torch.rsqrt(x.pow(2).mean(-1, keepdim=True) + self.eps)

    def forward(self, x: torch.Tensor) -> torch.Tensor:
        # 1) .float() 升 FP32 防平方溢出与累加截断 → 2) rsqrt 硬件倒数平方根 → 3) .type_as(x) 转回 BF16/FP16
        return self.weight * self._norm(x.float()).type_as(x)
  • 原因 ① 防 FP16 平方上溢（Overflow → NaN）：FP16 最大可表示正数仅为 65504。大模型深层常出现幅度破百的异常激活通道（Outlier Features），一旦某个分量 $|x_i| = 300 > 256$，在 FP16 下直接算 x.pow(2) 得到 $90000 > 65504 \implies \text{inf}$，紧接着 x / inf = 0 或梯度 NaN 瞬间毁掉整轮训练！升到 FP32（上限 $3.4 \times 10^{38}$）则稳如泰山。
  • 原因 ② 防 BF16 累加精度截断与硬件加速：BF16 虽然指数位宽不怕溢出，但尾数只有 7 bit（不到 3 位十进制有效数字），对 $d=4096$ 个数做平方平均极易发生「大数吃小数」且令 eps=1e-6 失效；同时用 torch.rsqrt 调用 GPU SFU 硬件单指令直接算 $1/\sqrt{\cdot}$，省去一次浮点除法。
  • 原因 ③ 为什么最后必须 .type_as(x)？如果不把归一化结果转回输入的 bfloat16 / float16，下游紧接着的 q_proj / k_proj 线性层要么报 dtype 不匹配错误，要么被迫退化为慢速 FP32 矩阵乘，Tensor Core 吞吐量直接腰斩！

模块二：MiniMindBlock 中的 Pre-Norm 双残差骨架

class MiniMindBlock:
    def __init__(self, cfg, layer_id):
        self.norm1 = RMSNorm(cfg['hidden_size'])
        self.attn = GQAAttention(cfg, seed=3 + layer_id)
        self.norm2 = RMSNorm(cfg['hidden_size'])
        self.ffn = SwiGLU(cfg, seed=5 + layer_id)
    def forward(self, h, freqs_cis, mask=None, cache=None, positions=0):
        # 子层 1：RMSNorm → GQA 注意力 → 残差
        a, kvcache = self.attn.forward(self.norm1(h), freqs_cis, mask, cache, positions)
        h = h + a
        # 子层 2：RMSNorm → SwiGLU → 残差
        h = h + self.ffn(self.norm2(h))
        return h, kvcache

block = MiniMindBlock(cfg, 0)
o_b, _ = block.forward(emb_in, freqs_cis, positions=0)
print('MiniMindBlock:', emb_in.shape, '->', o_b.shape)
  1. 两个独立归一化实例：self.norm1 服务 Attention，self.norm2 服务 FFN。两者各自拥有独立的可学习缩放向量 gamma，绝不能共用同一个实例！
  2. 第一段 Pre-Norm 残差（Token 间混合）：先拿 self.norm1(h) 把幅度稳住送入 attn，算完增量 a 后直接加回未经归一化的原主干 h。
  3. 第二段 Pre-Norm 残差（通道内非线性加工）：同理 h = h + self.ffn(self.norm2(h))。注意整座 $L$ 层大厦全部走完后，进最终分类头 lm_head 之前还必须补上第 $2L+1$ 个 final RMSNorm，用来兜底驯服一路累加膨胀的主干方差！

06小结

本课核心四句话
  • 残差恒等高速公路：$x_L = x_l + \sum F_i$ 使反向雅可比矩阵恒带单位阵 $\mathbf{I}$，把危险的跨层梯度连乘变成加法保底。
  • Pre-Norm 胜在主干纯净：Post-Norm 把归一化卡在主干上每次反向除以 $\sigma$，深层梯度衰减严重；Pre-Norm 把归一化移入支路入口，主干零阻尼直通到底（仅需在 lm_head 前补一个 Final Norm）。
  • RMSNorm 极简高效：砍掉 LayerNorm 的均值 $\mu$ 与偏置 $\beta$，只算一趟均方根 $\text{RMS}(x) = \sqrt{\text{mean}(x^2)+\epsilon}$，省去一次 HBM 显存读写归约，提速 10%–30% 且精度无损。
  • 混合精度铁律：工业级 RMSNorm.forward 必须先 x.float() 升 FP32 算平方均值与 torch.rsqrt，最后再 .type_as(x) 转回 BF16/FP16。

「现代开源大模型相比 2017 原版 Transformer，在归一化与残差上有两项标配升级：第一是把 Post-LN 改为 Pre-Norm，让残差主干变成不经过任何缩放的纯恒等加法通路，反向梯度可以借单位阵 $\mathbf{I}$ 无损回传到浅层，大幅降低对长 Warmup 的依赖；第二是把 LayerNorm 换成 RMSNorm，省掉均值中心化和偏置 $\beta$，因为归一化是典型的显存带宽受限算子，少算一趟均值能省掉一次全局归约读写、提速约 10%–30%。工程实现上要注意混合精度训练时必须先 .float() 转 FP32 算平方均值与 rsqrt，防止异常大激活在 FP16 下平方溢出成 NaN，算完再 .type_as(x) 转回半精度。」

07想检验一下？（可选 · 点击展开）

1. 快速口算：把本课向量 $x = [2, -1, 3, 0]$ 整体放大 $3$ 倍变成 $3x = [6, -3, 9, 0]$（忽略极小项 $\epsilon$），RMSNorm 的输出会变大 $3$ 倍还是保持不变？

保持完全不变（严格正向缩放不变性）！因为对任意正常数 $\lambda > 0$，$\text{RMS}(\lambda x) = \sqrt{\frac{1}{d}\sum (\lambda x_i)^2} = \lambda\,\text{RMS}(x)$，分子分母的 $\lambda$ 精确约掉：$\frac{\lambda x}{\lambda\,\text{RMS}(x)} = \frac{x}{\text{RMS}(x)}$。若乘负数 $-\lambda$，则输出刚好反号。

2. 🎤 面试深挖（二/三层）：Pre-Norm 既然这么稳，它有什么隐藏副作用？为什么超大模型（如 Gemma-2、Qwen3、ViT-22B）又开始引入 QK-Norm 或 Sandwich-Norm？

第一层（副作用：主干方差膨胀与深层表示退化 Representation Collapse）：因为 Pre-Norm 主干没有任何归一化，每叠一层都会往上加一个子层增量，导致第 $l$ 层主干方差随深度线性累积 $\text{Var}(x_l) \approx 1 + l\sigma^2$。到了第 60 层以后，主干模长已经很大，当前层经归一化后算出的单位量级增量 $F_l(\text{Norm}(x_l))$ 相对庞大的 $x_l$ 只像挠痒痒——深层网络趋向恒等映射「偷懒」，有效深度利用率不如训稳后的 Post-Norm。

第二层（注意力 Logit 尖峰崩塌）：百亿/千亿模型在大峰值学习率下，个别通道会出现极大值导致 $QK^\top/\sqrt{d_k}$ 点积爆炸，Softmax 退化成 One-Hot，注意力熵瞬间归零、梯度断流。

第三层（现代前沿补丁方案）：① QK-Norm（ViT-22B / Qwen3 / Chameleon）：在进入 RoPE 与点积前，对每个头的 $Q$ 和 $K$ 单独做一次 RMSNorm，从数学上给点积加上硬上界，彻底根治注意力爆炸；② Sandwich-Norm / Peri-LN（Gemma-2）：除了子层入口有 Pre-Norm，在子层输出汇入残差主干前再夹一层 RMSNorm，既保留主干恒等直通，又锁死了每层增量的方差上限；③ 残差缩放初始化（GPT-2 / MiniMind）：把每层出口投影矩阵 $W_o, W_{\text{down}}$ 的初始标准差乘上 $\frac{1}{\sqrt{2L}}$，使 $L$ 层累加后的初始总方差依然受控为 $\mathcal{O}(1)$。

3. 🎤 面试追问：一座 32 层（num_hidden_layers=32）的标准 LLaMA / MiniMind 模型，全身上下一共包含多少个独立的 RMSNorm 层？参数量总共多少？

一共 $2 \times 32 + 1 = \mathbf{65}$ 个 RMSNorm 层！每个 Transformer Block 内有 2 个（attn_norm 与 ffn_norm），外加所有 Block 走完后、进 lm_head 之前的 1 个顶层 final_norm。以 $d = 4096$ 为例，总参数量仅 $65 \times 4096 = 266{,}240 \approx 0.27\text{M}$（不到 7B 总参数的万分之零点四，四两拨千斤！）。
