# Mission: 27 届 LLM · Agent · 具身智能（VLA）算法实习通关

## Why
从零构建一条贯通「深度学习底座 → 轻量 LLM 预训练/SFT/DPO/GRPO → 零框架 Agent 与 Agentic RL → 机器人运动学/模仿学习/VLA」的可复现技术栈与作品集，拿下 27 届高含金量日常实习并在 2027 春招具备三层追问抗压与现场手撕能力。

## Success looks like
- 对简历上的每一个核心算子（反向传播、Attention、RoPE、LoRA、DPO/GRPO、RRF、雅可比阻尼伪逆、ACT/DP），能脱稿画出数据流与 Shape、手推关键梯度/目标函数，并解释每一行代码为什么这样写。
- 独立交付 P1–P5 五个有真实量化对比指标的实战项目（W08 产出简历 v1 投日常实习，W16 产出简历 v2 冲春招）。
- 所有学过的核心专题沉淀为可快速回看的交互式 HTML 课程页与 1–2 页速查表。

## Constraints
- **算力分工**：主力本机 RTX 4080 Laptop 12GB（BF16 + SDPA/FA2，Conda Python 3.11 环境）跑日常实验与中小模型；Colab T4 16GB 仅用 FP16；远程 A800 80GB 跑 vLLM、3B Agentic RL 与重型 VLA。
- **教学方式**：以讲透直觉、原理、公式与真实代码为目标，默认不强制练习或考核；卡壳超 2 天触发熔断保主线。
- **单一进度源**：周级里程碑只认 `ROADMAP_16W.md`，课题分课只认各课题 `计划.md`。

## Out of scope
- 传统搜广推、时间序列、语音、大数据数仓、运筹启发式算法、Go/Java 后端开发（详见 `REFERENCE_INDEX.md` 屏蔽清单）。
