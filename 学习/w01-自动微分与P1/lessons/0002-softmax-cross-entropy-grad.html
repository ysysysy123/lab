01痛点与直觉：为什么分类任务不用 Sigmoid + MSE？

很多初学者第一次写分类器时，会自然地把回归任务里的均方误差（MSE）搬过来：先把线性打分 $z$ 用 $\sigma(z) = \frac{1}{1+e^{-z}}$ 压到 $(0, 1)$ 区间，再最小化 $L_{\text{MSE}} = \frac{1}{2}(\sigma(z) - y)^2$。看似顺理成章，一旦开始梯度下降却会出现诡异的「越错越学不动」假死现象。

从 Sigmoid 到 Softmax 只有一步之遥：二分类里正类概率 $\sigma(z) = \frac{1}{1+e^{-z}} = \frac{e^z}{e^z + e^0}$，本质就是「正类打分 $z$」与「负类基准分 $0$」做两类 Softmax！推广到 $K$ 个类别（如 MNIST 10 个数字、MiniMind 32,000 个词元），就是把每个类别的原始打分 $z_i$ 取指数再归一化：$p_i = \frac{e^{z_i}}{\sum_{j=1}^K e^{z_j}}$。

直接拿一组真实数字拆穿病根——假设真实标签 $y = 1$，而模型当前预测错得离谱，给出了 $z = -5.0$：

  • 前向输出 $\sigma(-5.0) \approx 0.006693$，局部斜率已经掉进左侧平坦饱和区：$\sigma'(-5.0) = \sigma(1-\sigma) \approx 0.006648$。
  • 若用 MSE：链式法则给出 $\frac{\partial L_{\text{MSE}}}{\partial z} = (\sigma - y)\cdot\sigma(1-\sigma) = (-0.993307)\times 0.006648 \approx \mathbf{-0.006604}$！对比半蒙半猜的 $z = 0$（梯度为 $-0.125$），犯错更离谱时，梯度反而萎缩了近 19 倍——饱和导数 $\sigma'(z)$ 像一脚刹车把误差信号掐死了。
  • 若换二元交叉熵（BCE）：$L_{\text{BCE}} = -[y\ln\sigma + (1-y)\ln(1-\sigma)]$。外层对 $\sigma$ 求导自带分母 $\frac{\sigma - y}{\sigma(1-\sigma)}$，与内层 $\sigma'(z) = \sigma(1-\sigma)$ 分子分母当场一刀约掉！对 $z$ 的梯度直接化简为 $\sigma - y \approx \mathbf{-0.993307}$，推力比 MSE 猛 150.4 倍！
指数与对数的「天作之合」

Sigmoid / Softmax 里藏着指数 $e^z$，交叉熵里藏着负对数 $-\ln p$。对数把乘除拆成加减，求导时又刚好把 Sigmoid / Softmax 的饱和导数项抵消干净，只留下最纯粹的物理量——「模型预测概率 $p$ 与真实目标 $y$ 的差值」：错得越远推力越猛，猜对时（$p \to y$）自动平滑刹车。

读懂 $[-0.2946,\ +0.2595,\ +0.0351]$ 背后的三条物理直觉
  1. 正确类 $z_0$ 的梯度必为负（$p_0 - 1 = -0.2946$）：因为梯度下降执行 $z_0 \leftarrow z_0 - \eta g_0$，减去一个负数等于向上推高正确类的分数！若取步长 $\eta = 0.5$，$z_0$ 会从 $2.0$ 升至 $2.1473$。
  2. 错误类 $z_1, z_2$ 的梯度必为正（$p_i - 0 = p_i$），且按「抢占概率比例」精准打压：$z_1$ 抢走了 $25.95\%$ 的概率，就挨 $+0.2595$ 的重锤；$z_2$ 只占 $3.51\%$ 几乎没捣乱，就只受 $+0.0351$ 的轻推。一步更新后，$p_0$ 立刻从 $70.54\%$ 涨到 $75.70\%$，损失 $L$ 从 $0.3490$ 降到 $0.2784$。
  3. 零和守恒力场：把三个梯度加起来：$-0.294615 + 0.259496 + 0.035119 = \sum_{i} p_i - 1 = \mathbf{0.0}$！向上拔高正确类的总力道，分毫不差等于向下压低所有错误类的力道之和（这也对应 Softmax 平移不变性：所有 $z_i$ 同加常数 $c$ 概率不变，故方向导数 $(1,1,1)\cdot \nabla_z L = 0$）。

03分步符号推导：四步证出灵魂公式 $p - y$

面试手撕时千万不要一上来硬套商法则 $\left(\frac{u}{v}\right)' = \frac{u'v - uv'}{v^2}$！秘诀是「先用对数把除法拆成减法，再求偏导」，四步就能极其优雅地走完全程（按 → 逐步展开保留）：

设共有 $K$ 个类别，当前样本真实类别索引为 $y \in \{1,\dots,K\}$。单样本交叉熵只挑出真实类 $y$ 的负对数概率，利用 $\ln(A/B) = \ln A - \ln B$ 与 $\ln(e^{z_y}) = z_y$ 直接展开：

$$L = -\ln p_y = -\ln \frac{e^{z_y}}{\sum_{j=1}^K e^{z_j}} = \underbrace{\ln \sum_{j=1}^K e^{z_j}}_{\text{LogSumExp 项}} - z_y$$

这一步用了：对数商法则。原本棘手的分式瞬间变成了「一项对数和」减去「一项线性变量 $z_y$」！

对第一项套复合函数链式法则 $\frac{\partial}{\partial z_y}\ln u = \frac{1}{u}\frac{\partial u}{\partial z_y}$（求和号 $\sum_{j=1}^K e^{z_j}$ 里只有 $j=y$ 那一项含 $z_y$，导数为 $e^{z_y}$）；第二项 $-z_y$ 对 $z_y$ 的偏导是 $-1$：

$$\frac{\partial L}{\partial z_y} = \frac{1}{\sum_{j=1}^K e^{z_j}} \cdot e^{z_y} - 1 = p_y - 1$$

当 $i \neq y$ 时，第一项求和号里依然只有 $j=i$ 那一项含 $z_i$，导数为 $e^{z_i}$；而第二项 $-z_y$ 与 $z_i$ 无关，偏导直接为 $0$：

$$\frac{\partial L}{\partial z_i} = \frac{1}{\sum_{j=1}^K e^{z_j}} \cdot e^{z_i} - 0 = p_i \qquad (i \neq y)$$

引入 One-hot 向量 $y_i = \mathbb{1}[i = y]$（当 $i=y$ 时为 $1$，否则为 $0$），上面两种情形完美合二为一：

$$\frac{\partial L}{\partial z_i} = p_i - \mathbb{1}[i = y] = p_i - y_i$$

当一个 Batch 有 $B$ 个样本且总损失取均值 $\bar{L} = \frac{1}{B}\sum_{b=1}^B L^{(b)}$ 时，把 $B$ 行拼成矩阵即得反向传播第一棒：

$$\mathrm{d}Z = \frac{\partial \bar{L}}{\partial Z} = \frac{1}{B}(P - Y)$$

(批量灵魂梯度)

$$\mathrm{d}Z_2 = \frac{1}{B}(P - Y) \in \mathbb{R}^{B \times K}$$

$P \in \mathbb{R}^{B \times K}$
Softmax 输出概率矩阵，每行是一个样本在 $K$ 个类别上的预测分布（行和为 $1$）
$Y \in \mathbb{R}^{B \times K}$
目标分布矩阵：标准多分类下为 One-hot；在大模型标签平滑（Label Smoothing）或知识蒸馏软标签下，只要满足每行 $\sum_j Y_{b,j} = 1$，此公式依然一字不改原样成立！
$\frac{1}{B}$
批量平均因子，对应前向 loss = np.mean(...)。若漏除 $B$，梯度幅值会随 batch_size 暴涨 $B$ 倍！
选读：从 Softmax 雅可比矩阵 $\frac{\partial p_j}{\partial z_i} = p_j(\delta_{ij} - p_i)$ 再证一遍（为第 3 周 Attention 反向传播埋伏笔！）

如果后续算子不是交叉熵——例如第 3 周 Transformer 自注意力 $O = \text{softmax}(S) V$，不能跟 $-\ln$ 合并化简时，我们就必须单独求出 Softmax 本身的雅可比矩阵（Jacobian）：

对 $p_j = \frac{e^{z_j}}{\Sigma}$（记 $\Sigma = \sum_k e^{z_k}$）应用商法则：

  • 当 $i = j$（对角线）：$\frac{\partial p_i}{\partial z_i} = \frac{e^{z_i}\Sigma - e^{z_i}\cdot e^{z_i}}{\Sigma^2} = p_i - p_i^2 = p_i(1 - p_i)$。
  • 当 $i \neq j$（非对角线）：分子 $e^{z_j}$ 对 $z_i$ 导数为 $0$，故 $\frac{\partial p_j}{\partial z_i} = \frac{0 - e^{z_j}\cdot e^{z_i}}{\Sigma^2} = -p_j p_i$。

用克罗内克符号 $\delta_{ij} = \mathbb{1}[i=j]$ 统一写成：$$\frac{\partial p_j}{\partial z_i} = p_j(\delta_{ij} - p_i)$$

现在把它代入一般分布交叉熵 $L = -\sum_{j=1}^K y_j \ln p_j$（其中 $\sum_j y_j = 1$）的链式法则：

$$\frac{\partial L}{\partial z_i} = \sum_{j=1}^K \frac{\partial L}{\partial p_j}\frac{\partial p_j}{\partial z_i} = \sum_{j=1}^K \left(-\frac{y_j}{p_j}\right) p_j(\delta_{ij} - p_i) = -\sum_{j=1}^K y_j(\delta_{ij} - p_i) = -y_i + p_i\underbrace{\sum_{j=1}^K y_j}_{=1} = p_i - y_i$$

看！$-\frac{1}{p_j}$ 与雅可比外面的 $p_j$ 像齿轮一样严丝合缝消掉了！而在 Self-Attention 中，已知上游梯度 $\mathrm{d}P$，根据同一雅可比就能一行写出注意力分数梯度 $\mathrm{d}S = P \odot \big(\mathrm{d}P - \text{rowsum}(\mathrm{d}P \odot P)\big)$——这就是 FlashAttention 反向核的数学心脏。

下面截取本仓 P1 实战脚本 projects/p1-tiny-llm/src/w01_mlp_mnist.py 第 55–105 行真实源码。点击右侧讲解卡片定位每一处工程防坑细节：

    @staticmethod
    def softmax(z: np.ndarray) -> np.ndarray:
        # 防数值溢出减去 max
        shift_z = z - np.max(z, axis=1, keepdims=True)
        exp_z = np.exp(shift_z)
        return exp_z / np.sum(exp_z, axis=1, keepdims=True)

    def forward(self, X: np.ndarray) -> tuple[np.ndarray, np.ndarray, np.ndarray, np.ndarray]:
        """
        前向传播:
        X: (B, 784)
        返回: (Z1, A1, Z2, P)
        """
        Z1 = X @ self.W1 + self.b1           # (B, hidden_dim)
        A1 = np.maximum(0, Z1)                # ReLU: (B, hidden_dim)
        Z2 = A1 @ self.W2 + self.b2          # (B, out_dim)
        P = self.softmax(Z2)                 # Softmax 概率分布: (B, out_dim)
        return Z1, A1, Z2, P

    def train_step(self, X: np.ndarray, y: np.ndarray) -> float:
        """
        X: (B, 784)
        y: (B,) 类别索引 0~9
        """
        B = X.shape[0]
        Z1, A1, Z2, P = self.forward(X)

        # 1. 计算交叉熵损失
        log_likelihood = -np.log(P[np.arange(B), y] + 1e-12)
        loss = float(np.mean(log_likelihood))

        # 2. 构造 One-Hot 标签 Y
        Y = np.zeros_like(P)
        Y[np.arange(B), y] = 1.0

        # =================================================================
        # TODO(human): 手撕矩阵反向传播 (4 行核心数学公式)
        # 提示:
        # dZ2 = (P - Y) / B                       # Softmax+CrossEntropy 优雅导数: (B, 10)
        # dW2 = ...                               # (hidden_dim, 10)
        # db2 = ...                               # (1, 10)
        # dA1 = ...                               # (B, hidden_dim)
        # dZ1 = dA1 * (Z1 > 0)                    # ReLU 局部导数: (B, hidden_dim)
        # dW1 = ...                               # (in_dim, hidden_dim)
        # db1 = ...                               # (1, hidden_dim)
        # =================================================================
        # 下面 7 行请你在弄清维度后补全，跑通训练：
        dZ2 = (P - Y) / B
        dW2 = A1.T @ dZ2
        db2 = np.sum(dZ2, axis=0, keepdims=True)
  1. 平移防溢出 Softmax：若某行 logit 达到 $1000$，np.exp(1000) 会直接溢出成 inf。先减去每行最大值 $m = \max_j z_j$，等价于分子分母同乘 $e^{-m}$，概率值分毫不差，且所有指数项 $\le e^0 = 1$！注意 keepdims=True 保持 (B, 1) 才能按行广播。
  2. Logits Z2 与概率 P 分离：Z2 形状 (B, 10) 是线性层原始打分（不要在 Z2 后再套 ReLU，否则负数打分全被截断成 0！）；P 存下前向概率供反向直接复用。
  3. 花式索引挑出真实类概率：P[np.arange(B), y] 一次性取出第 $b$ 行第 $y_b$ 列元素，得到形状 (B,) 的正确类概率向量，加 1e-12 防止 log(0) 产生 NaN（第 4 课会升级为工业级 logsumexp 融合算子）。
  4. 两行构造 One-hot 矩阵 Y：用 np.zeros_like(P) 创建 (B, 10) 全零阵，再用相同的花式索引把每行真实数字位置填为 1.0。
  5. 反向传播点火 dZ2 = (P - Y) / B：直接落地 §3 推导结果！无需显式构造 $10\times 10$ 雅可比矩阵，一行数组减法同时完成 Softmax 与 Cross-Entropy 两层回传，除以 B 对齐第 84 行的 np.mean。

06小结

本课浓缩四句话
  • 不用 MSE 做分类的根因：MSE 求导保留了激活函数导数 $\sigma'(z) = \sigma(1-\sigma)$，当模型严重判错掉进饱和区时梯度趋近于 $0$，越错越学不动。
  • 先拆对数再求导：$L = -\ln\frac{e^{z_y}}{\sum_j e^{z_j}} = \ln\sum_j e^{z_j} - z_y$，无需商法则，直接得出正确类偏导 $p_y - 1$、错误类偏导 $p_i$。
  • 灵魂梯度公式：单样本 $\frac{\partial L}{\partial z} = p - y$，批量平均 $\mathrm{d}Z = \frac{1}{B}(P - Y)$，且每样本梯度分量之和恒为 $\sum_i (p_i - y_i) = 0$。
  • 工程防溢出底线：手写 Softmax 必须先减行最大值 z - np.max(z, axis=1, keepdims=True)，绝不裸跑 np.exp(z)。

「分类任务坚持用 Softmax 搭配交叉熵而非 MSE，核心是为了消除激活饱和区的梯度消失：交叉熵里的负对数导数 $-1/p_y$ 恰好与 Softmax 导数里的 $p_y$ 因子约分抵消，把对 logits 的梯度化简为极其干净的 $\frac{1}{B}(P - Y)$。它的物理意义非常直观：预测越离谱，$(p_y - 1)$ 的绝对值越接近 1，纠偏推力越强；同时错误类别严格按其误抢占的概率比例 $p_i$ 被向下压制，所有类别梯度之和恒为 0。」

07想检验一下？（可选 · 点击展开）

1. 如果把三个类别的 logits $[2.0, 1.0, -1.0]$ 同时加上 $100$ 变成 $[102.0, 101.0, 99.0]$，概率 $p$、损失 $L$ 和梯度 $p - y$ 会变吗？裸写 np.exp(z) 何时会炸？

数学上完全不变！因为 $\frac{e^{z_i + c}}{\sum_j e^{z_j + c}} = \frac{e^c e^{z_i}}{e^c \sum_j e^{z_j}} = p_i$，所以概率 $p$、损失 $L$ 与梯度 $p - y$ 连最后一位小数都不变。但在 IEEE-754 双精度浮点数（FP64）中，$e^{710}$ 就会溢出为 inf（在训练大模型常用的 FP16 中，$e^{11.1} > 65504$ 就会溢出！），导致 inf / inf = nan 瞬间训崩——这就是减去 $\max_j z_j$ 不可省略的原因。

2. 🎤 面试高频追问：大模型和视觉训练常加 Label Smoothing（标签平滑，系数 $\epsilon$），此时平滑目标是什么？对 logits 的梯度公式要怎么改？

设类别数为 $K$（或词表大小 $V$），平滑系数为 $\epsilon \in (0, 1)$。标签平滑把原本独霸 $1$ 的 One-hot 目标 $y$ 抽出 $\epsilon$ 的概率质量，均匀撒给全部 $K$ 个类：

$$\tilde{y}_i = (1 - \epsilon) y_i + \frac{\epsilon}{K}$$

例如本课 3 分类算例取 $\epsilon = 0.1,\ y=0$，目标从 $[1, 0, 0]$ 变为 $\tilde{y} = [0.933333, 0.033333, 0.033333]$。最妙的是梯度公式一个结构都不用改——因为在 $L = -\sum_{j=1}^K \tilde{y}_j \ln p_j$ 中，只要目标分布满足 $\sum_{j=1}^K \tilde{y}_j = (1-\epsilon) + K\cdot\frac{\epsilon}{K} = 1$，链式推导： $$\frac{\partial L}{\partial z_i} = \frac{\partial}{\partial z_i}\left(\ln\sum_k e^{z_k}\underbrace{\sum_{j=1}^K \tilde{y}_j}_{=1} - \sum_{j=1}^K \tilde{y}_j z_j\right) = p_i - \tilde{y}_i = p_i - \left[(1-\epsilon)y_i + \frac{\epsilon}{K}\right]$$

物理含义：当正确类预测概率 $p_y$ 达到 $1 - \epsilon + \epsilon/K$（上例中约 $93.33\%$）时梯度就归零收手，不再逼迫正确类 logit 飙向 $+\infty$，从而防止模型过度自信（Over-confidence）、提升泛化与校准度！

3. 🎤 面试防坑追问：在 PyTorch 里定义分类网络时，如果在最后一层 nn.Linear 后面多手写了一层 F.softmax(x, dim=-1)，再喂给 nn.CrossEntropyLoss()，会发生什么后果？

等于做了「双重 Softmax」，训练会严重退化甚至卡死！因为 PyTorch 的 nn.CrossEntropyLoss 内部已经融合了 F.log_softmax + F.nll_loss，它期望的输入是未归一化的原始 logits $\in (-\infty, +\infty)$。如果你提前算过一次 Softmax，输入全被压缩在 $[0, 1]$ 区间：即使某个类概率高达 $1.0$、其余为 $0.0$，再过一次 Softmax 后最大概率也只有 $\frac{e^1}{e^1 + (K-1)e^0}$（在 10 分类 MNIST 上最高不超过 $e/(e+9) \approx 23.2\%$！），损失有极高的下界且梯度被二次饱和严重削弱。
