# 教学偏好与工作便签（NOTES · v2）

- **唯一入口防迷路**：每天只看 `PLAN.md` 当前周的**下一条未完成任务**，以及昨天 `daily/` 日志留下的 **「下次从这里开始（明天第一件事）」**。全天主块只做一个主题，绝不在一天内多线切换。
- **讲课减负 · 模块结束必做三级验收**：
  - 讲新概念时先给痛点直觉（≤3 句）与 **2×2 极小具体数值例子**，再展开公式推导与真实代码逐行映射，讲课中途不打断。
  - 每个模块学完（及每周五验收日），必须过 **L1 讲得出（口述痛点/Shape/为什么）→ L2 写得出（限时盲写 15–40 行核心代码过 assert）→ L3 扛得住（3 层追问 + 先预测后实跑的预测题）**。
- **防遗忘机制（自写复习卡 + 间隔复习）**：
  - 每天开头 15 分钟运行 `python3 study.py review` 自测到期卡片（1→3→7→14→30→60 天）。
  - 每天收尾用**自己的话**写 3–5 张复习卡存入 `学习/cards/*.md`（一卡一问，答案 ≤3 行），由 AI 协助检查准确性。
- **代码与数值洁癖**：优先采用上层 `../` AI Tutorial 原始 `.ipynb` 课程和 `lab/`（`concepts/`、`projects/`）里的真实源码；所有算例数字与交互读数必须与 Python 金标准一致。
