# 教学偏好与工作便签（NOTES）

- **讲解节奏偏好**：以真正听懂、看通为第一目标。先给痛点直觉（不超过 3 句）与 **2×2 极小具体数值例子**，再展开符号公式推导和真实代码逐段拆解，最后配可拖动参数的交互式可视化。
- **不强制练习或考核**：正文直接把核心公式和代码讲透，不故意挖空卡进度；自测题和面试追问统一折叠在 HTML 页面底部供自愿点开。只有在我主动说「练一下 / 盲写 / 考考我」时才出盲写题或模拟面。
- **代码与数值洁癖**：优先采用上层 `../` AI Tutorial 原始 `.ipynb` 课程和 `lab/`（`concepts/`、`projects/`）里的真实代码，保持变量命名与行号真实可查；页面中的所有算例数字与交互读数必须与 Python 金标准一致。
- **分轮体量**：单节 HTML 课程聚焦 1 个核心突破点（15–25 分钟读完），大课题拆成 3–6 节小课按「继续」逐轮推进。
