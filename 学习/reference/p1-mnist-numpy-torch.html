2. 核心张量 Shape 追踪表 (Batch=128)

符号张量形状物理意义与数学关系
$X$(128, 784)批次展平图像，经标准归一化
$W_1, b_1$(784, 128), (1, 128)隐层参数（He/Kaiming 随机初始化）
$Z_1, A_1$(128, 128)$Z_1 = X W_1 + b_1$；$A_1 = \max(0, Z_1)$ (ReLU)
$W_2, b_2$(128, 10), (1, 10)输出层参数
$Z_2, P$(128, 10)Logits 分数 $Z_2 = A_1 W_2 + b_2$；$P = \operatorname{softmax}(Z_2)$
$\mathrm{d}Z_2$(128, 10)$\mathrm{d}Z_2 = (P - Y) / B$（Softmax+交叉熵灵魂化简梯度）

3. NumPy 两层 MLP 反向 7 行核心模板

# ① 输出层误差梯度：由 Softmax+CE 灵魂化简而来
dZ2 = (P - Y) / B                       # (B, 10)

# ② 输出层权重梯度：前向 A1 @ W2，消 B 维并累加全批次
dW2 = A1.T @ dZ2                        # (128, 10)
db2 = np.sum(dZ2, axis=0, keepdims=True)# (1, 10)

# ③ 回传隐层激活：前向 Z2 = A1 @ W2，消 10 维
dA1 = dZ2 @ self.W2.T                   # (B, 128)

# ④ ReLU 门控反传：Z1 > 0 处通流，其余截断
dZ1 = dA1 * (Z1 > 0)                    # (B, 128)

# ⑤ 隐层权重与偏置梯度：消 B 维
dW1 = X.T @ dZ1                         # (784, 128)
db1 = np.sum(dZ1, axis=0, keepdims=True)# (1, 128)

4. PyTorch GPU 工业级五步训练闭环

# 1. 结构与参数对齐：nn.Linear 内部存储转置 (out, in)
model = nn.Sequential(nn.Linear(784, 128), nn.ReLU(), nn.Linear(128, 10)).to(device)
criterion = nn.CrossEntropyLoss()       # 内置 Log-Sum-Exp 融合计算
optimizer = torch.optim.SGD(model.parameters(), lr=lr)

# 2. 标准训练五步闭环
for x, y in train_loader:
    x, y = x.to(device), y.to(device)
    optimizer.zero_grad()               # ① 清理残留梯度（底层 +=）
    with torch.autocast(device_type=device.type, dtype=torch.bfloat16, enabled=use_bf16):
        logits = model(x)              # ② 前向输出原始 logits（严禁加 Softmax）
        loss = criterion(logits, y)    # ③ 融合损失计算
    loss.backward()                    # ④ 逆拓扑序求导
    optimizer.step()                   # ⑤ 优化器更新参数
    loss_sum += loss.item() * len(y)   # ⑥ loss.item() 防显存泄漏

5. 三大工程避坑红线

  • 红线一：严禁在输出层后接 nn.Softmax()：nn.CrossEntropyLoss 内部融合了 log_softmax，重复 Softmax 会导致 10 分类 Loss 锁死在 $\ge \ln(e+9)-1 \approx \mathbf{1.4612}$，且两端导数饱和致梯度假死。
  • 红线二：权重转置差异：数学上 $Z = XW$，PyTorch nn.Linear 计算 $x A^\top + b$，其 weight 维度为 (out_features, in_features)。权重初始化注入必须用 W.T。
  • 红线三：记录日志必须取 loss.item()：直接累加 loss 会把整个 Batch 的前向计算图挂在内存中，迅速触发 GPU OOM。

6. 30 秒面试表达模板

「在手撕 MLP MNIST 实战中，我用 NumPy 和 PyTorch GPU 分别跑出了 97.73% 与 97.71% 的严格对齐准确率。矩阵反向传播的核心推导是利用张量形状对齐：输出层由 Softmax 交叉熵解析求导得到 $\mathrm{d}Z_2 = (P - Y)/B$，而权重梯度 $\mathrm{d}W_2 = A_1^\top \mathrm{d}Z_2$ 利用矩阵乘法天然完成了 Batch 内所有样本外积的并行累加。而在 PyTorch 工业级落地时，关键是最后一层必须输出裸 logits 让 nn.CrossEntropyLoss 在内部做 Log-Sum-Exp 融合计算，既防止浮点数在 $e^z$ 时发生上溢崩溃，又避免了概率 $p$ 下溢为 0 导致损失截断和梯度断流。」
