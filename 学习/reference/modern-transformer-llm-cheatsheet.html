1. 缩放点积与因果多头注意力

$$\text{Attention}(Q, K, V) = \text{softmax}\!\left(\frac{QK^\top}{\sqrt{d_k}} + M_{\text{causal}}\right)V$$

  • 为何除以 $\sqrt{d_k}$：$q_i, k_i \sim (0,1)$ 独立时 $\text{Var}(q\cdot k)=d_k$；不缩放会导致 Softmax 饱和为 One-hot，雅可比梯度 $\to 0$。
  • 因果掩码铁律：$j > i$ 必须在 Softmax 之前填 $-\infty$（使 $e^{-\infty}=0$ 且行和仍为 $1$；切勿在 Softmax 之后置零）。
  • MHA Shape 流：(B,T,C) → view(B,T,H,d_k) → transpose(1,2) → (B,H,T,d_k) → SDPA → transpose(1,2).contiguous().view(B,T,C) → Wo。

2. RoPE 旋转位置编码

$$R_m = \begin{pmatrix}\cos m\theta & -\sin m\theta \\ \sin m\theta & \cos m\theta\end{pmatrix}, \quad (R_m q)^\top (R_n k) = q^\top R_{n-m} k$$

  • 核心优势：用绝对位置原地旋转（完美兼容 KV Cache，历史 Key 无需重算）实现严格相对位置内积与远程自然衰减。
  • 多频波长：$\theta_j = \text{base}^{-2j/d}$（高频分量辨局部词序，低频分量管超长上下文；长文本外推常调大 $\text{base}$ 至 $5\times 10^5 \sim 10^6$）。

3. Pre-Norm + RMSNorm 与 SwiGLU

Pre-Norm 残差主干（恒等项 $\mathbf{I}$ 保百层梯度直通）：

$$h = x + \text{Attn}(\text{RMSNorm}(x)), \quad y = h + \text{SwiGLU}(\text{RMSNorm}(h))$$

RMSNorm（省去均值中心化，半精度下必转 FP32 算均方根）：

$$\text{RMSNorm}(x) = \frac{x}{\sqrt{\frac{1}{d}\sum_{i=1}^d x_i^2 + \epsilon}} \odot \gamma$$

SwiGLU（三矩阵总参数 $3 d d_{ff} = 8 d^2 \implies d_{ff} \approx \frac{8}{3}d$）：

$$\text{SwiGLU}(x) = \big(\text{SiLU}(x W_{\text{gate}}) \odot (x W_{\text{up}})\big) W_{\text{down}}$$

4. GQA 与 KV Cache 显存口算公式

$$\text{KV Bytes} = 2 \times L \times H_{kv} \times d_k \times B \times T \times \text{bytes}$$
