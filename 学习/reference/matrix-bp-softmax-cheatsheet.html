矩阵反向传播与 Softmax+交叉熵速查卡

手撕两层 MLP、推导 $p - y$ 灵魂梯度与 Log-Sum-Exp 数值稳定性的 1 页浓缩资产

📅 更新于 2026-11-02 🔗 来源：w01 第 2–4 课 💻 projects/p1-tiny-llm/src/w01_mlp_mnist.py

1. Softmax + 交叉熵与 Log-Sum-Exp

平移不变防上溢（令 $m = \max_j z_j$，指数最大输入恒为 $0$）：

$$p_i = \frac{e^{z_i - m}}{\sum_{j=1}^K e^{z_j - m}}, \qquad L = -\log p_y = m - z_y + \log \sum_{j=1}^K e^{z_j - m}$$

灵魂梯度（对数与指数互逆抵消，无 Sigmoid+MSE 饱和因子）：

$$\frac{\partial L}{\partial z_i} = p_i - \mathbb{1}[i = y], \qquad \mathrm{d}Z_2 = \frac{1}{B}(P - Y)$$

2. 批量矩阵 BP 维度拼图双铁律

  • 同形铁律：梯度张量 $\mathrm{d}T$ 必须与原张量 $T$ 形状完全一致。
  • 消维铁律：$Z = A W + b$（$A \in \mathbb{R}^{B\times H},\ W \in \mathbb{R}^{H\times K},\ \mathrm{d}Z \in \mathbb{R}^{B\times K}$）：
    • 求 $\mathrm{d}W \in (H, K)$ 消掉 $B$：$\mathrm{d}W = A^\top \mathrm{d}Z$
    • 求 $\mathrm{d}A \in (B, H)$ 消掉 $K$：$\mathrm{d}A = \mathrm{d}Z \, W^\top$
    • 求 $\mathrm{d}b \in (1, K)$ 回收广播：$\mathrm{d}b = \sum_{b=1}^B \mathrm{d}Z[b, :]$

3. NumPy 两层 MLP 反向 7 行核心模板

dZ2 = (P - Y) / B                        # (B, 10)
dW2 = A1.T @ dZ2                         # (128, 10)
db2 = np.sum(dZ2, axis=0, keepdims=True) # (1, 10)

dA1 = dZ2 @ self.W2.T                    # (B, 128)
dZ1 = dA1 * (Z1 > 0)                     # (B, 128) ReLU 掩码
dW1 = X.T @ dZ1                          # (784, 128)
db1 = np.sum(dZ1, axis=0, keepdims=True) # (1, 128)

4. 高频防坑清单

  • nn.CrossEntropyLoss 前严禁加 Softmax：内部已融合 F.log_softmax + NLLLoss。
  • 权重严禁全 0 初始化：会导致同层所有隐藏元前向激活与反向梯度恒等（对称性死锁）；ReLU 层配 Kaiming 初始化 $\mathcal{N}(0, 2/d_{\text{in}})$。
  • 三端精度防溢出：RTX 4080 开 bf16（动态范围同 FP32）；Colab T4 仅支持 fp16（$\exp(11.1)$ 即溢出，必做减 $\max$）。
