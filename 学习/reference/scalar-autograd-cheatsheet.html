1. 单步反向传播通式

$$\text{child.grad} \;\mathrel{+}=\; \frac{\partial\,\text{out}}{\partial\,\text{child}} \cdot \text{out.grad}$$

算子 $\text{out}$局部导数 $\partial\,\text{out}/\partial a$直觉角色
$a + b$$1$梯度路由器（原样分发）
$a \cdot b$$b$互换搭档前向值（需存激活）
$a^k$$k a^{k-1}$幂函数法则
$\tanh(a)$$1 - \text{out}^2$直接复用前向输出 $t$
$\text{ReLU}(a)$$\mathbb{1}[a > 0]$正区直通、负区截断为 0
$\exp(a)$$\text{out}$导数等于自身前向输出

2. backward() 三条铁律

  • 起点置 1：self.grad = 1.0（对应 $\frac{\partial L}{\partial L}=1$，否则全图乘 0）。
  • 支路累加 +=：同一节点多路复用（如 $a\cdot a + a$、残差分支）按全导数法则求和；所以每次迭代前必须 zero_grad()。
  • DFS 逆拓扑序：用 visited 去重后序遍历再 reversed(topo)，保证下游梯度全汇齐后才向更上游回传。

中心差分梯度检验（$\epsilon = 10^{-6}$，误差 $O(\epsilon^2)$）：

$$g_{\text{num}} = \frac{L(w + \epsilon) - L(w - \epsilon)}{2\epsilon}$$

3. 15 行手撕核心模板

def backward(self) -> None:
    topo: list[Value] = []
    visited: set[Value] = set()

    def build_topo(v: Value) -> None:
        if v not in visited:
            visited.add(v)
            for child in v._prev:
                build_topo(child)
            topo.append(v)

    build_topo(self)
    self.grad = 1.0
    for node in reversed(topo):
        node._backward()

4. 高频防坑与 30 秒面试表达

  • 为什么用反向模式而非前向模式？ 输入参数 $N$ 极大而 Loss 是 1 个标量，反向模式 1 趟拿齐全部 $N$ 个偏导（前向模式需 $N$ 趟）。
  • 为什么训练显存远大于参数显存？ 乘法门与非线性门在反向求导时必须读取前向缓存的激活张量。
  • 梯度检验易错点：解析梯度与数值差分必须在同一组输入与权重状态下对比，且避开 ReLU 在 $z=0$ 处的不可导折点。
