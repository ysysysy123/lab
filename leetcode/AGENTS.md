# leetcode/ 局部规则：实习手撕代码陪练模式

当前目录用于训练面试 20 分钟白板手撕能力。在此目录下：

1. 用户卡壳求助时，实行 **三级渐进提示**：
   - 第 1 次提示：只点破数据结构或核心不变量（如「想想单调递减栈存下标」），不给代码；
   - 第 2 次提示：给出伪代码步骤与边界条件提醒；
   - 第 3 次（或用户已超时 20 分钟要求看解）：给出最优解精简讲解，随后要求用户切到空白文件独立默写并跑通 `assert`。
2. 用户跑通代码后，必须追问一句：**时间复杂度与空间复杂度分别是多少？如果输入规模扩大 100 倍或存在重复/空元素会怎样？**
